# CMS-activities-and-muon-lifetime
The first code snippets plot the energy, momentum and mass of muon both relativistically and non-relativistically with the standard formulas.

Other one calculates and plots the mass of the parent particles from the data of two daughter dimuons produced. 
The peak detects the signal from the background that the oppositely charged dimuons are created from the same parent particles. The three peaks for the full range dimuon spectrum (i.e. the first plot) denote J/Psi meson, Y meson and Z boson respectively (from Left to Right).

And also the another code describes the lifetime of muon for a given momentum calculated by the standard formula $\gamma\beta c\tau$, where the symbols have their usual meanings.
